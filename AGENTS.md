# Project Instructions

## Project overview

EBTools is a collection of free online tools. The project is under active development and currently includes a working image-converter prototype.

## General guidance

- Preserve the existing lightweight structure and conventions of the project.
- Keep changes focused on the user's request.
- Prefer clear, accessible interfaces that work well on desktop and mobile.
- Avoid adding dependencies unless they are needed for the requested feature.
- Do not overwrite or remove user content without a clear need.
- Explain which files changed and any relevant limitations when reporting completed work.

## Change workflow and approval

- Make only one change at a time.
- Before changing code, explain the proposed change and wait for the user's approval.
- After making a change, wait for the user to test and approve it before moving on to the next change.
- Do not rewrite working code without a good reason.
- When fixing a bug, change only the section needed to fix it.
- After each change, explain which files were affected.

## Before changing code

- Inspect the relevant HTML, CSS, and JavaScript files to understand the current implementation.
- Reuse existing patterns and assets where practical.
- Keep user-facing text consistent with the language already used by the affected page, unless the user requests another language.

## Verification

- Run checks only when requested by the user or needed to diagnose an issue.
- If a change cannot be verified in the available environment, say so clearly.
